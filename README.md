# 盘松 · PANSONG

一个**零 Docker、零数据库依赖、纯 Node.js 跨平台（macOS / Windows / Linux）**的私人影视海报墙与多网盘资源聚合检索引擎，采用**「东方极简 · 松烟墨与宣纸风 (Neo-Oriental Pine & Ink)」**设计语言。

## ✨ 核心特性

- **开箱即用，全平台通用**：无任何二进制或 Docker 依赖，仅需 Node.js (`>= 18`)，在 macOS、Windows、Linux 上一键 `npm start` 运行。
- **无限流影视海报墙主视图**：
  - 内置 **10 大豆瓣影视分类**（`热播剧集`、`热门电影`、`豆瓣高分`、`国产剧`、`动漫番剧`、`美剧`、`日韩剧`、`热门综艺`、`纪录片`、`冷门佳片`）与 **3 种排序**（`按热度` / `按最新` / `按高分`）；
  - 后端内置豆瓣封面防盗链代理与 LRU 内存缓存（`GET /api/poster`），支持 `IntersectionObserver` 无限滚动翻页；
  - 点击任意海报即刻切入多网盘流式检索，支持一键返回海报墙并**精准恢复原先的浏览滚动位置**。
- **双引擎并发 + SSE 流式渐进聚合 (`GET /api/search/stream`)**：
  1. **41 个 Telegram 公开资源频道并发直采**（免 TG 账号、免 API Key，支持频道健康度监控与一键剔除失效频道）。
  2. **10 路主流网盘资源站直连插件 + 自动熔断器 (Circuit Breaker)**：内置小酷盘 `xiaokupan`、影盘社 `melost`、爱看资源 `ikantv`、小云搜索 `yunso`、影搜 `yingso`、爱盼影视 `aipan`、488影视 `488run`、夸克搜 `quarksoo`、二小盘 `erxiaopan`、聚合加速源 `mipan_relay`。
- **结果脱水、规格墨印提纯与同源多盘折叠**：
  - 自动剥离引流话术并降权营销噪音，提纯 `4K`、`杜比`、`HDR`、`原盘`、`60帧`、`高码`、`全集`、`更至XX集` 墨印标签；
  - 自动将同一剧集下的不同网盘（如夸克 + 百度 + 阿里）折叠为「同源备选」，避免刷屏。
- **批量死链检测与网盘内真实文件透视验货**：
  - 对当前页展示的夸克、百度、阿里、天翼、115、迅雷、UC、123 等网盘链接异步检测存活状态；
  - 在验活同时透视网盘内真实分享文件夹名/文件名与文件大小（`实测：xxx (52.4 GB)`），防挂羊头卖狗肉。
- **贴心交互体验**：
  - **纯前端零依赖手机扫码直达**（`public/qrcode.js`）：点击「扫码」即生成 SVG 二维码，手机网盘 App 扫码直接转存；
  - **智能复制提取码**：点击「直达 ↗」自动将提取码复制到剪贴板；
  - **宣纸 / 松烟双主题**：温润护眼，内置本地私藏书签、搜索历史与可视化代理探测面板。

## 🚀 快速启动

### macOS / Linux
```bash
git clone https://github.com/huyusong10/panso.git
cd panso
npm install
npm start
# 或者直接执行 ./start.sh
```

### Windows
双击运行 `start.bat`，或在终端执行：
```powershell
npm install
npm start
```

启动后浏览器访问：**`http://localhost:3200`**（局域网内其他设备可直接访问终端输出的 `Network` IP 地址）。

## ⚙️ 配置文件

所有配置（端口、代理地址、启用的插件、Telegram 频道列表）首次启动时自动生成在 `data/config.json`，也可以直接在网页右上角点击 **「设置」** 在线可视化修改并即时生效。
